# VulnHub Labs

Hands-on penetration-testing practice using intentionally vulnerable virtual machines from VulnHub.

This repository documents my methodology for reconnaissance, enumeration, vulnerability identification, exploitation, privilege escalation, and remediation.

---

## 🎯 Objectives

* Practice real-world penetration-testing methodology
* Improve Linux and network enumeration skills
* Understand vulnerability exploitation
* Practice privilege escalation
* Document findings clearly and professionally
* Develop repeatable security-testing methodology

## 🔍 Methodology
 
The general workflow used for each machine is:

```text
Reconnaissance
      ↓
Enumeration
      ↓
Attack Surface Analysis
      ↓
Vulnerability Identification
      ↓
Exploitation
      ↓
Initial Access
      ↓
Privilege Escalation
      ↓
Proof of Compromise
      ↓
Remediation
```
